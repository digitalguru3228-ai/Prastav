
# Prastav

A web-based employee approval management system.

## Project Overview

Prastav helps organizations manage employee requests through a structured, multi-level approval workflow.

## Technology Stack

- React
- Vite
- JavaScript
- Supabase Authentication
- Supabase PostgreSQL
- Tailwind CSS

## User Roles

- Employee
- Approver
- Admin
